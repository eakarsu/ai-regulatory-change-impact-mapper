# Regulatory change impact runbook

Each authoritative change version carries publisher, HTTPS source URI, jurisdiction, publication/effective/retrieval dates, version, content digest, and provenance. Analysts map it to explicit policies, controls, products, contracts, processes, and systems; every obligation has an accountable owner, deadline when applicable, bounded risk, and citation. Independent review plus a passing scenario evaluation gates approval/publication. Decisions and impact snapshots are append-only. Legal holds override retention deletion, and audit exports must be access-controlled and redacted.

Install dependencies explicitly and run `./start.sh check`. Back up PostgreSQL, then use `ALLOW_SCHEMA_MIGRATION=1 ./start.sh migrate`. A local development administrator may be provisioned separately with `ADMIN_EMAIL`, a 12+ character `ADMIN_PASSWORD`, and `npm --prefix backend run create-admin`; production password login remains disabled. Build before `./start.sh start`; startup never installs, seeds, migrates, creates databases, or kills processes. Monitor source freshness/change detection, unowned impacts, approaching effective dates, overdue remediation, failed evaluations, unauthorized release attempts, and legal-hold changes. Preserve citations and decisions through recovery.

The application implements OIDC authorization code with PKCE, discovery, state/nonce validation, JWKS signature verification, issuer/audience checks and deny-by-default role/tenant claim mapping. Register the callback, store client credentials in the deployment secret manager, approve `OIDC_ROLE_MAP_JSON` and `OIDC_TENANT_CLAIM`, enforce MFA at the IdP, and test login/logout and tenant isolation before production release. Licensed authoritative feeds, regulator source completeness, legal interpretation, jurisdiction-specific obligation validation, approved retention/legal-hold and recipient-specific export procedures, security testing, representative compliance-user acceptance, and production-environment recovery testing remain external launch gates. The mapper does not constitute legal advice or regulatory certification.
